## Сделано
- Отдельный applicationId: ru.kalandos240.animalspop (debug: .debug).
- Gradle 8.9, AGP 8.7.3, Java 17, compile/target SDK 35.
- AdMob заменён Yandex Mobile Ads 8.6.0, только добровольная rewarded-реклама.
- Награда выдаётся один раз, после закрытия рекламы и только при onRewarded.

- Русские строковые ресурсы. Надписи, нарисованные внутри изображений, пока не переведены.
- CI: debug APK и Android Lint, отчёты и APK в артефактах Actions.

## Проверка
GitHub Actions / Android RuStore — источник фактического результата сборки.
На устройстве ещё нужно проверить меню, обучение, уровни, звук, сворачивание,
сохранение прогресса и все варианты наград (просмотр, закрытие, отсутствие сети).
Проверить в том числе Android 15: отступы системных панелей, кнопки, жесты.

## Сборка
Установить JDK 17, Android SDK 35. Выполнить:

```sh
bash gradlew :app:assembleDebug :app:lintDebug
```

Debug использует demo-rewarded-yandex, заработка на нём нет.
Для release указать свой блок РСЯ:

```sh
bash gradlew :app:assembleRelease -PyandexRewardedAdUnitId=R-M-1234567-1
```

Release без реального ID блокируется. Release APK пока НЕ подписан:
подписать собственным постоянным ключом через Android Studio / apksigner.
Не отправлять ключ и пароли в репозиторий или чат.

## До публикации
1. Проверить лицензию каждого стороннего изображения/звука. README исходника
   указывает pngtree, SoundCloud Free Music и mixkit; MIT файла с кодом
   не доказывает коммерческие права на эти материалы. При отсутствии подтверждения заменить.
2. Подключить приложение и rewarded-блок в своём кабинете РСЯ.
3. Определить возрастную аудиторию; согласовать настройки обработки данных/рекламы
   с требованиями РСЯ, особенно если приложение рассчитано на детей.
4. Подготовить политику конфиденциальности с фактическими данными разработчика
   и описанием обработки данных рекламным SDK. Политика пока не добавлена.
5. Протестировать на устройстве без Google Play Services.
6. Подписать APK, подготовить скриншоты, описание, возрастную маркировку и загрузить в RuStore.

Это подготовительная версия, не готовый к публикации релиз.
